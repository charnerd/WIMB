# Where is My Baby? (WIMB)

WIMB is a 3D minigame created on the Unity Game Engine using C#. 
Game Link: [Play](https://play-prod.struckd.com/api/v1/games/game/e8278a77-b5d6-4838-9b13-0f013440f82a/build/latest/frame)

**Movement and Controls**
1) WASD/Arrow Keys - move up and down or left and right
2) E - interact with items

In this game, you play as a babysitter trying to find the baby who's missing in the park. You have to interact with the green magnifying class icons to get clues; the more clues found makes it easier to find the child.

**Here are some things to remember:**
1) You have 12 minutes before the game is over.
2) Clues found will stay on the screen so you can keep track of what you have found so far (some may have information, some will not)
3) The score increases with the more clues you found (a multiplier) and you get a bonus for finding the correct kid.

**Tips and Tricks**
1) Interact with all the clues that you can find!
2) Try to go to areas with more space (nearby trees, playgrounds); they are more likely to have clues or a kid near it.
